# Java Javalin Starter Kit
A minimal Java 26 API starter.

### Tools used
- [javalin](https://central.sonatype.com/artifact/io.javalin/javalin/versions) as a minimal API
- [jackson-databind](https://central.sonatype.com/artifact/com.fasterxml.jackson.core/jackson-databind) for object mapping (java to json and vice versa)
- [slf4j-simple](https://central.sonatype.com/artifact/org.slf4j/slf4j-simple) for logs
- [junit-jupiter](https://central.sonatype.com/artifact/org.junit.jupiter/junit-jupiter) for tests

### How-to
0. Check that you have java 26 (java --version) and maven (mvn --version) installed. Use IntelliJ for least friction.
1. Run `mvn test` to build. (View --> Tool windows --> Maven and Reload Maven is also helpful.)
2. Bon appetit!
